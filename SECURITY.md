# Security Policy

## Supported versions

Only the latest release receives security fixes.

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅        |
| Older          | ❌        |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues.**

Report them privately via
[GitHub Security Advisories](https://github.com/afshinghezeli/claude-rtl-extension/security/advisories/new).
Include a description, steps to reproduce, the affected version and the
potential impact.

You can expect an initial response within **7 days**. Once confirmed, a fix is
prioritised and released, and you will be credited in the advisory unless you
prefer otherwise.

## Scope

In scope: the extension code in this repository (content script, popup,
service worker, build pipeline).

Out of scope: vulnerabilities in claude.ai itself — please report those
directly to Anthropic.
