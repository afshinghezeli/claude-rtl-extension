# Third-party notices

Claude RTL bundles the following fonts. Each is licensed under the
[SIL Open Font License, Version 1.1](https://openfontlicense.org); the full
license text ships next to the font files in `src/fonts/<font>/OFL.txt`.

| Font      | Author                                                      | Source                                      | License |
| --------- | ----------------------------------------------------------- | ------------------------------------------- | ------- |
| Vazirmatn | The Vazirmatn Project Authors (Saber Rastikerdar et al.)    | https://github.com/rastikerdar/vazirmatn    | OFL-1.1 |
| Shabnam   | Saber Rastikerdar (Latin glyphs from Roboto, Apache-2.0)    | https://github.com/rastikerdar/shabnam-font | OFL-1.1 |
| Sahel     | Saber Rastikerdar                                           | https://github.com/rastikerdar/sahel-font   | OFL-1.1 |
| Samim     | Saber Rastikerdar (Latin glyphs from Open Sans, Apache-2.0) | https://github.com/rastikerdar/samim-font   | OFL-1.1 |

The fonts are distributed unmodified. Inside the extension they are registered
under prefixed family names (e.g. `CRTL Vazirmatn`) to avoid clashing with
fonts already present on the page; the font files themselves are not renamed.
